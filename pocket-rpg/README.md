# Pocket RPG

Первая игровая вертикаль текстовой RPG по мотивам Pocket Combats.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run app:build
```

В текущей вертикали реализованы общий уровень персонажа и автоматический рост характеристик, навыки, инвентарь, переходы между локациями, базовый бой, лут, локальные сохранения, рыбалка, сбор ресурсов, фермерство, крафт и алхимия, многогородская динамическая торговля, дипломатия и фракционная репутация, университетское переобучение характеристик, а также поражение с травмами и восстановлением.

Сбор ресурсов — автоматическая мирная активность с фокусом на травы, ягоды или растительное волокно. Фокус меняет вероятности, но не гарантирует конкретный ресурс. Успешный сбор открывает точное название ресурса, редкие варианты заменяют обычный результат и дают больше опыта навыка. Запасы локаций не истощаются. Активный сбор прекращается при переходе, бое, торговле, начале другой мирной работы или перезагрузке.

Рыбалка и сбор ресурсов используют реальную массу инвентаря: при нагрузке 120% и выше начать мирную активность нельзя.

Фермерство включает постоянные поля, последовательную посадку, рост культур по реальному времени даже при закрытой игре, сбор зрелых клеток, редкие варианты урожая и развитие навыка. Активная незавершённая работа прерывается при перезагрузке, переходе, бое или торговле. На нейтральных сельскохозяйственных землях во время активной работы возможны редкие слабые нападения.

После поражения персонаж остаётся в текущей локации, на 15 секунд теряет сознание и получает травму. Травмы сохраняются между запусками. При травмах всех шести зон запускается принудительный отдых; слабые/средние/сильные средства позволяют лечить соответственно 2, 4 или все уровни травм.

Крафт в городских мастерских мгновенный и гарантированный. Рецепт задаёт точные типы и количество материалов; материалы разных классов можно смешивать, а класс результата определяется их средневзвешенным классом. Экипировка хранится отдельными экземплярами, получает собственную редкость и свойства, создаётся на +0 и может гарантированно улучшаться до +5. На +3 и +5 добавляются свойства, а переброс одного изменяемого свойства стоит фиксированное количество золота. Обычный крафт ограничен Epic — Unique остаётся наградой редкого контента.

Алхимия использует ресурсы сбора и фермерства. Боевые зелья занимают одно дополнительное предметное действие раунда и ограничены насыщенностью: максимум 100, после завершённого раунда снимается 20. Это не распространяется на средства лечения травм — они по-прежнему применяются только вне боя по правилам системы травм.

Торговая сеть включает Тилланиум, Карнхольм, Элларию, Ривермарк и Гринвальд. Города отличаются ассортиментом и базовым дефицитом/профицитом. Массовая покупка повышает локальную цену следующей единицы на 5%, массовая продажа создаёт локальный профицит; личное давление полностью нормализуется за 12 реальных часов. Рыночные события работают шестичасовыми окнами. Навык торговли, Харизма и отношения с городской фракцией дают ограниченное преимущество, но не отменяют городской ценовой профиль. Межгородские грузы имеют заметную массу и используют общую систему перегруза.

Дипломатия работает в Карнхольме, Элларии, Ривермарке и Гринвальде. У каждой фракции есть отдельные отношения от −100 до +100, дипломатический навык, аудиенции раз в 2 часа, медиации с навыка 20 раз в 6 часов и сменяющееся шестичасовое товарное поручение. Аудиенция даёт до +1 отношения без штрафа при неудаче; медиация даёт +2 при успехе и −1 при провале; поручение требует конкретный товар и даёт +3 отношения, опыт дипломатии и компенсацию 50% базовой стоимости. При отношении 50+ открывается один локальный товар фракции. Влияние отношений на торговые цены остаётся ограниченным прежними ±5%.

Университеты доступны в Тилланиуме и Элларии. Переобучение открывается с 10 уровня и переносит очки специализации между характеристиками за 1 реальный час. Базовые +1 к каждой характеристике за каждый уровень не перераспределяются. Из специализационной части до 80% донорских очков могут участвовать в переобучении, но у донора дополнительно сохраняется минимум 5% общего специализационного пула. Перенос можно задать как 25/50/75/100% доступной части; сумма характеристик не меняется. Одновременно возможно только одно переобучение, оно завершается по реальному времени и после закрытия игры.

Общий уровень персонажа использует 1000 XP для перехода с 1 на 2 уровень и рост требования на 15% за уровень. Общий XP дают уже существующие игровые действия: бой, рыбалка, сбор, фермерство, крафт/алхимия, успешные продажи и дипломатические действия. Для мирных профессий общий XP совпадает с уже начисляемым XP соответствующего действия; бой даёт 40 + 20 × уровень противника. Покупки, лечение, улучшение и переброс экипировки сами по себе общего XP не дают.

Каждый источник общего XP имеет собственный профиль характеристик. До следующего уровня профиль накапливается пропорционально полученному XP. При повышении уровня каждая из восьми характеристик гарантированно получает +1, а оставшиеся 7 очков автоматически распределяются по накопленному профилю; после уровня профиль сбрасывается. Если одна награда переливается через границу уровня, использованная часть влияет на текущий уровень, а остаток формирует профиль уже следующего. Ручного распределения нет.

Сохранения автоматически мигрируют с schema v1/v2/v3/v4/v5/v6/v7/v8 на schema v9. Schema v9 сохраняет накопленный профиль источников XP вместе с уровнем, текущим XP, характеристиками и университетским переобучением, поэтому будущая специализация не теряется после перезапуска.
