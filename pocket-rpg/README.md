# Pocket RPG

Первая игровая вертикаль текстовой RPG по мотивам Pocket Combats.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run app:build
```

В текущей вертикали реализованы характеристики и навыки, инвентарь, переходы между локациями, базовый бой, лут, локальные сохранения, рыбалка, минимальная торговля, а также поражение с травмами и восстановлением.

После поражения персонаж остаётся в текущей локации, на 15 секунд теряет сознание и получает травму. Травмы сохраняются между запусками. При травмах всех шести зон запускается принудительный отдых; слабые/средние/сильные средства позволяют лечить соответственно 2, 4 или все уровни травм. Сохранения автоматически мигрируют с schema v1 на schema v2.

Многогородская экономика, университеты, фермерство, полный набор профессий, фракции и расширенные призывы остаются следующими этапами.
