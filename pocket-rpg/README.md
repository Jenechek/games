# Pocket RPG

Первая игровая вертикаль текстовой RPG по мотивам Pocket Combats RPG.

## Запуск

```bash
cd pocket-rpg
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run typecheck
npm run build
```

## Что уже входит в первую вертикаль

- 8 характеристик и общий опыт персонажа;
- иерархические навыки 0–100;
- инвентарь по массе, экипировка и перегруз;
- пять связанных локаций и переходы 4–8 секунд;
- автоматический/ручной бой с 5-секундными раундами;
- базовый лут;
- IndexedDB-сохранения;
- автоматическая рыбалка;
- Тилланиум и базовый торговец.

Полная экономика нескольких городов, университеты, фракции, фермерство, полный крафт, расширенные призывы и остальной контент будут добавляться последующими вертикалями согласно утверждённой спецификации.
