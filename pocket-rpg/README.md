# Pocket RPG

Первая игровая вертикаль текстовой RPG по мотивам Pocket Combats.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run app:build
```

В текущей вертикали реализованы характеристики и навыки, инвентарь, переходы между локациями, базовый бой, лут, локальные сохранения, рыбалка, сбор ресурсов, фермерство, крафт и алхимия, минимальная торговля, а также поражение с травмами и восстановлением.

Крафт и алхимия используют точные рецепты и специализированные мастерские Тилланиума. Материалы поступают из Gathering/Farming и от городского торговца. Рецепты можно изучать из свитков; повторный свиток превращается в 5 золота. Экипировка создаётся отдельными экземплярами с качеством Common/Quality/Rare/Epic, улучшениями +0…+5 и перебрасываемыми свойствами. Улучшения гарантированы и требуют золота. Алхимия создаёт стекуемые зелья и лекарства.

Крафт может привести к перегрузу и сам по себе не блокируется текущей нагрузкой; при этом Fishing, Gathering и Farming по-прежнему требуют нагрузку ниже 120%.

Сбор ресурсов — автоматическая мирная активность с фокусом на травы, ягоды или растительное волокно. Фокус меняет вероятности, но не гарантирует конкретный ресурс. Успешный сбор открывает точное название ресурса, редкие варианты заменяют обычный результат и дают больше опыта навыка.

Фермерство включает постоянные поля, последовательную посадку, рост культур по реальному времени даже при закрытой игре, сбор зрелых клеток, редкие варианты урожая и развитие навыка.

После поражения персонаж остаётся в текущей локации, на 15 секунд теряет сознание и получает травму. Травмы сохраняются между запусками.

Сохранения автоматически мигрируют с schema v1/v2/v3/v4 на schema v5.

Многогородская экономика, университеты, дипломатия, фракции, полная система экипировки и расширенные призывы остаются следующими этапами.
