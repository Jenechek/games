# Pocket RPG

Первая игровая вертикаль текстовой RPG по мотивам Pocket Combats.

## Запуск

```bash
npm install
npm run dev
```

## Проверки ядра

```bash
npm test
```

В первой вертикали реализуются характеристики и навыки, инвентарь, переходы между локациями, базовый бой, лут, локальные сохранения, рыбалка и минимальная торговля. Многогородская экономика, университеты, фермерство, полный набор профессий, фракции и расширенные призывы остаются следующими этапами.
