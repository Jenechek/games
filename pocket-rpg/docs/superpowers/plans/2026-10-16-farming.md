# Farming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persistent fields, timed planting, offline crop growth, sequential harvesting, farming skill progression, save migration, neutral interruptions, and a React farming panel.

**Architecture:** Implement farming as a pure TypeScript subsystem under `src/game-core/peaceful/farming/`. Persistent `FarmingState` is part of `GameState`; runtime-only `FarmingWork` remains in the React application state so reload interrupts active work while crop timestamps continue offline.

**Tech Stack:** TypeScript, React, Vite, Node test runner, IndexedDB, GitHub Actions.

**Spec:** `pocket-rpg/docs/superpowers/specs/2026-10-16-farming-design.md`

## Global Constraints

- Field establishment is exactly 30 seconds and grants no XP.
- Planting/harvesting operate one field at a time, one cell at a time.
- Seeds are unlocked once and never consumed.
- Crops grow 5–30 minutes in the starter content and continue offline.
- Planting XP is exactly 50% of normal harvest XP.
- Rare harvest replaces ordinary output and keeps the same quantity.
- Active farming work is not persisted.
- Save schema becomes v3 with v1/v2 migrations.
- Recovery locks block farming.
- Neutral farming has a 2% interruption roll after each completed work cell.

## Review Focus

- Reload during planting/harvest must not finish the active work but already completed cells must remain.
- Abandoning a field with crops must delete those crops permanently and free a slot.
- A skill-level increase must expand existing field capacity without deleting or duplicating cells.
- Partial harvest must keep `cycleCropId` until every planted cell is gone.
- Corrupted v3 farming data must fail closed instead of reaching React.
